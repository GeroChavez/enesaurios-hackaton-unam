# enesaurios-hackaton-unam

**Estado del proyecto:** DECOY IQ es una herramienta dirigida a analistas y cuerpos técnicos que estima el valor táctico indirecto de los receptores que no reciben el balón mediante un índice experimental (DVI). El motor de análisis está desarrollado y revisado, pero aún no se ha validado con datos reales. Se cuenta con 126 archivos CSV (825 MB) del Big Data Bowl 2021, cuya viabilidad ya fue auditada. Los datos originales se conservan sin modificaciones.
